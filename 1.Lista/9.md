## (d) Distribuição de Frequências — Variável Metodologia

Variável qualitativa ordinal com conceitos **A, B, C, D** (ordem decrescente de desempenho).

| Conceito | $f_i$ | $f_{ri}$ | $f_{ri}\%$ | $F_i$ | $F_{ri}\%$ |

> Nenhum funcionário obteve conceito **D** em Metodologia.  
> A moda é **C** (9 ocorrências, 36%).  
> 64% dos funcionários obtiveram conceito **A ou B** (aproveitamento satisfatório).

## (e) Probabilidade de Grau A em Metodologia

> **Problema:** sorteado **ao acaso 1** funcionário dos 25, qual a probabilidade de ele ter obtido grau A em Metodologia?

Da tabela de frequências: **8 funcionários** obtiveram grau A  
(funcionários nº 1, 5, 6, 16, 22, 23, 24 e 25).

$$P(\text{grau A}) = \frac{f_A}{n} = \frac{8}{25} = 0{,}32 = \mathbf{32\%}$$

> Há uma chance de **32%** de que o funcionário sorteado tenha obtido grau A em Metodologia.

## Código Python utilizado

```python
from collections import Counter
from math import comb

data = [
    # (Func, Seção, Administ, Direito, Redação, Estatist, Inglês, Metodologia, Política, Economia)
    (1,'P',8.0,9.0,8.6,9.0,'B','A',9.0,8.5),
    (2,'P',8.0,9.0,7.0,9.0,'B','C',6.5,8.0),
    # ... (25 linhas)
]

# (d) Distribuição de frequências — Metodologia
met = [r[7] for r in data]
counts = Counter(met)
n = len(data)

acum = 0
for k in ['A', 'B', 'C', 'D']:
    fi = counts[k]
    acum += fi
    print(f"{k}: fi={fi}, fri={fi/n:.4f}, Fi={acum}")

# (e) Probabilidade de grau A
fa = counts['A']
prob = fa / n
print(f"P(A) = {fa}/{n} = {prob:.4f}")
```
