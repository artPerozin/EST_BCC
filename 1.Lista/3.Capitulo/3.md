## (b) Medida de Posição Central e de Dispersão

### Média

$$\bar{x} = \frac{\sum x_i}{n} = \frac{1.992}{49} \approx \mathbf{40{,}65 \text{ casas}}$$

### Mediana

Com n = 49, a mediana é o valor na **25ª posição** (dados ordenados).  
O 25º valor nos dados ordenados é **32**.

$$\text{Md} = \mathbf{32 \text{ casas}}$$

### Desvio Padrão (amostral)

$$s = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n-1}} \approx \mathbf{26{,}29 \text{ casas}}$$

### Interpretação

| Medida       | Valor        |
|:-------------|-------------:|
| Média        | 40,65 casas  |
| Mediana      | 32,00 casas  |
| Desvio Padrão| 26,29 casas  |

> A **mediana (32)** é mais adequada como medida de posição central neste caso, pois a **média (40,65)** é puxada para cima pelos valores extremos (89, 90, 92, 97).  
> O desvio padrão elevado (≈ 26) confirma a **alta variabilidade** no número de casas por quarteirão.

## Código Python

```python
import math, statistics

casas = [2,2,3,10,13,14,15,15,16,16,
         18,18,20,21,22,22,23,24,25,25,
         26,27,29,30,32,36,42,44,45,
         45,46,48,52,58,59,61,61,61,65,
         66,66,68,75,78,80,89,90,92,97]

n       = len(casas)                                          # 49
media   = sum(casas) / n                                      # 40.65
mediana = statistics.median(sorted(casas))                    # 32.0
var_s   = sum((x - media)**2 for x in casas) / (n - 1)
dp      = math.sqrt(var_s)                                    # 26.29

# Histograma com 5 classes de amplitude 20
classes = [(0,20),(20,40),(40,60),(60,80),(80,100)]
for a, b in classes:
    fi = sum(1 for x in casas if a <= x < b)
    print(f"[{a}|--{b}): fi={fi}")
```
