## (b) Média da Amostra $\bar{x}$

Para dados agrupados, usando o ponto médio $x_i$ de cada classe:

$$\bar{x} = \frac{\sum x_i \cdot f_i}{n} = \frac{10.240}{200} = \boxed{\mathbf{51{,}20 \text{ sal. mín.}}}$$

## (d) Porcentagem entre $\bar{x} - 2s$ e $\bar{x} + 2s$

$$\bar{x} - 2s = 51{,}20 - 2 \times 6{,}635 = 51{,}20 - 13{,}27 = \mathbf{37{,}93}$$

$$\bar{x} + 2s = 51{,}20 + 2 \times 6{,}635 = 51{,}20 + 13{,}27 = \mathbf{64{,}47}$$

## (e) Mediana

A mediana é o valor que acumula **50% das observações** → posição $n/2 = 100$.

Da tabela de frequências acumuladas:

| Classe       | $F_i$ |
|:------------:|:-----:|
| [45 \|-- 50) |    80 | ← antes de 100
| **[50 \|-- 55)** | **150** | ← passa de 100 ✓

Usando a fórmula de interpolação:

$$\text{Md} = L + h \cdot \frac{\frac{n}{2} - F_{ant}}{f_{Md}}$$

Onde: $L = 50$, $h = 5$, $F_{ant} = 80$, $f_{Md} = 70$, $n/2 = 100$

$$\text{Md} = 50 + 5 \cdot \frac{100 - 80}{70} = 50 + 5 \cdot \frac{20}{70} = 50 + 1{,}4286 \approx \boxed{\mathbf{51{,}43 \text{ sal. mín.}}}$$

## Código Python

```python
import math

classes = [(30,35),(35,40),(40,45),(45,50),(50,55),(55,60),(60,65),(65,70)]
fi      = [2, 10, 18, 50, 70, 30, 18, 2]
n       = sum(fi)                          # 200
pm      = [(a+b)/2 for a,b in classes]    # pontos médios

# (b) Média
media = sum(m*f for m,f in zip(pm, fi)) / n   # 51.20

# (c) Desvio padrão
var = sum(f*(m-media)**2 for m,f in zip(pm, fi)) / (n-1)
dp  = math.sqrt(var)                           # 6.635

# (d) % entre media ± 2s
lo, hi = media - 2*dp, media + 2*dp
total_dentro = sum(
    min(b, hi) - max(a, lo)) / (b-a) * f
    for (a,b), f in zip(classes, fi)
    if min(b, hi) > max(a, lo)
)
pct = total_dentro / n * 100               # 94.12%

# (e) Mediana por interpolação
L, h, F_ant, f_md = 50, 5, 80, 70
Md = L + h * (n/2 - F_ant) / f_md         # 51.43
```
