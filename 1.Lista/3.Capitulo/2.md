# Questão 2 — Taxas de Juros de 10 Ações

> Taxas de juros recebidas (em %) por 10 ações durante um certo período:  
> **2,59 · 2,64 · 2,60 · 2,62 · 2,57 · 2,55 · 2,61 · 2,50 · 2,63 · 2,64**

---

## Média

$$\bar{x} = \frac{\sum x_i}{n} = \frac{2{,}59 + 2{,}64 + 2{,}60 + 2{,}62 + 2{,}57 + 2{,}55 + 2{,}61 + 2{,}50 + 2{,}63 + 2{,}64}{10}$$

$$\bar{x} = \frac{25{,}95}{10} = \mathbf{2{,}595\%}$$

---

## Mediana

Dados ordenados:

$$2{,}50 \quad 2{,}55 \quad 2{,}57 \quad 2{,}59 \quad \mathbf{2{,}60} \quad \mathbf{2{,}61} \quad 2{,}62 \quad 2{,}63 \quad 2{,}64 \quad 2{,}64$$

Com n = 10 (par), a mediana é a média dos valores na 5ª e 6ª posições:

$$\text{Md} = \frac{2{,}60 + 2{,}61}{2} = \mathbf{2{,}605\%}$$

---

## Desvio Padrão (amostral)

$$s = \sqrt{\frac{\sum (x_i - \bar{x})^2}{n-1}}$$

| $x_i$ | $x_i - \bar{x}$ | $(x_i - \bar{x})^2$ |
|------:|----------------:|--------------------:|
| 2,59  |         −0,005  |            0,000025 |
| 2,64  |          0,045  |            0,002025 |
| 2,60  |          0,005  |            0,000025 |
| 2,62  |          0,025  |            0,000625 |
| 2,57  |         −0,025  |            0,000625 |
| 2,55  |         −0,045  |            0,002025 |
| 2,61  |          0,015  |            0,000225 |

| 2,63  |          0,035  |            0,001225 |
| 2,64  |          0,045  |            0,002025 |
| **Σ** |                 |          **0,01785**|

$$s = \sqrt{\frac{0{,}01785}{9}} = \sqrt{0{,}001983} \approx \mathbf{0{,}0445\%}$$

---

## Interpretação

> As 10 ações têm taxa média de **2,595%** com desvio padrão muito pequeno (**0,0445%**), indicando que as taxas são bastante homogêneas — todas concentradas entre 2,50% e 2,64%.

## Código Python

```python
import math, statistics

acoes = [2.59, 2.64, 2.60, 2.62, 2.57, 2.55, 2.61, 2.50, 2.63, 2.64]
n = len(acoes)

media   = sum(acoes) / n                                      # 2.595
mediana = statistics.median(sorted(acoes))                    # 2.605
var_s   = sum((x - media)**2 for x in acoes) / (n - 1)
dp      = math.sqrt(var_s)                                    # 0.0445
```
