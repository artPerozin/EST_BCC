# Questão 1 — Erros de Impressão (n = 50 páginas)

> Uma amostra de 50 páginas de um livro foi analisada quanto ao número de erros de impressão por página.

## Tabela de Frequências

| Erros ($x_i$) | Frequência ($f_i$) | $x_i \cdot f_i$ | $f_{ri}\%$ |
|:-------------:|------------------:|----------------:|-----------:|
| 0             |                25 |               0 |     50,00% |
| 1             |                20 |              20 |     40,00% |
| 2             |                 3 |               6 |      6,00% |
| 3             |                 1 |               3 |      2,00% |
| 4             |                 1 |               4 |      2,00% |
| **Total**     |            **50** |          **33** | **100,00%**|

---

## (a) Número Médio de Erros por Página

$$\bar{x} = \frac{\sum x_i \cdot f_i}{n} = \frac{0 \cdot 25 + 1 \cdot 20 + 2 \cdot 3 + 3 \cdot 1 + 4 \cdot 1}{50} = \frac{33}{50} = \mathbf{0{,}66 \text{ erros/página}}$$

---

## (b) Número Mediano

Com n = 50, a mediana é a média dos valores nas posições **25ª e 26ª** (dados ordenados).

- Posições 1–25: valor **0** (25 ocorrências)
- Posições 26–45: valor **1** (20 ocorrências)

A 25ª observação = **0** e a 26ª observação = **1**

$$\text{Md} = \frac{0 + 1}{2} = \mathbf{0{,}5 \text{ erro}}$$

---

## (c) Desvio Padrão

$$s = \sqrt{\frac{\sum f_i(x_i - \bar{x})^2}{n-1}}$$

| $x_i$ | $f_i$ | $(x_i - \bar{x})$ | $(x_i - \bar{x})^2$ | $f_i(x_i - \bar{x})^2$ |
|:-----:|------:|------------------:|--------------------:|-----------------------:|
| 0     |    25 |            −0,660 |              0,4356 |                 10,890 |
| 1     |    20 |             0,340 |              0,1156 |                  2,312 |
| 2     |     3 |             1,340 |              1,7956 |                  5,387 |
| 3     |     1 |             2,340 |              5,4756 |                  5,476 |
| 4     |     1 |             3,340 |             11,1556 |                 11,156 |
| **Σ** |**50** |                   |                     |             **35,220** |

$$s = \sqrt{\frac{35{,}220}{49}} = \sqrt{0{,}7188} \approx \mathbf{0{,}848 \text{ erro}}$$

## (e) Total de Erros Esperado em 500 Páginas

$$\text{Total} = \bar{x} \times N = 0{,}66 \times 500 = \mathbf{330 \text{ erros}}$$

> Espera-se aproximadamente **330 erros** em um livro de 500 páginas.

---

## Código Python

```python
import math, statistics

# Dados expandidos
erros = [0]*25 + [1]*20 + [2]*3 + [3]*1 + [4]*1
n = 50

media   = sum(erros) / n                                     # 0.66
mediana = statistics.median(sorted(erros))                   # 0.5
var_s   = sum((x - media)**2 for x in erros) / (n - 1)
dp      = math.sqrt(var_s)                                   # 0.848
total   = media * 500                                        # 330.0
```
