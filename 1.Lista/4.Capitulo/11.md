## (c) Coeficiente de Correlação de Pearson

$$r = \frac{S_{xy}}{\sqrt{S_{xx} \cdot S_{yy}}}$$

Onde:
$$S_{xx} = \sum x_i^2 - n\bar{x}^2, \quad S_{yy} = \sum y_i^2 - n\bar{y}^2, \quad S_{xy} = \sum x_iy_i - n\bar{x}\bar{y}$$

### Valores médios

$$\bar{x} = \frac{2{,}0+2{,}5+2{,}9+3{,}3+4{,}1+4{,}3+7{,}0+13{,}0}{8} = \frac{39{,}1}{8} = 4{,}8875$$

$$\bar{y} = \frac{17{,}5+18{,}5+19{,}5+22{,}2+26{,}5+16{,}6+36{,}6+38{,}4}{8} = \frac{195{,}8}{8} = 24{,}475$$

### Somas

|:--------------|:------:|:------:|:--------------:|:--------------:|:----------------------------:|:-----------------:|:-----------------:|
| São Paulo     |  2,0   |  17,5  |  −2,888        |  −6,975        |          20,140              |        8,338      |        48,650     |

## (d) Região com Comportamento Atípico — Recalcular $r$

**Porto Alegre** apresenta comportamento discrepante: apesar de ter setor primário semelhante a Salvador (4,3% vs 4,1%), seu índice de analfabetismo é muito menor (16,6 vs 26,5). No diagrama, ela quebra a tendência geral.

## Código Python

```python
import math

x = [2.0, 2.5, 2.9, 3.3, 4.1, 4.3, 7.0, 13.0]
y = [17.5, 18.5, 19.5, 22.2, 26.5, 16.6, 36.6, 38.4]

def pearson(x, y):
    n = len(x)
    xb, yb = sum(x)/n, sum(y)/n
    Sxy = sum((xi-xb)*(yi-yb) for xi,yi in zip(x,y))
    Sxx = sum((xi-xb)**2 for xi in x)
    Syy = sum((yi-yb)**2 for yi in y)
    return Sxy / math.sqrt(Sxx * Syy)

r_full = pearson(x, y)                           # 0.8666

# Sem Porto Alegre (índice 5)
x2 = [v for i,v in enumerate(x) if i != 5]
y2 = [v for i,v in enumerate(y) if i != 5]
r_sem_pa = pearson(x2, y2)                       # 0.9082
```
