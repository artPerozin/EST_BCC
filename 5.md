## (b) Representação Gráfica — Grau de Instrução (Tabela 2.3)

Por se tratar de uma **variável qualitativa ordinal**, as representações mais adequadas são o **gráfico de barras** e o **gráfico de setores (pizza)**.

### Gráfico de Barras (horizontal)

```
Fundamental  |████████████████████████████████  650  (32,50%)
      Médio  |█████████████████████████████████████████████████████  1.020  (51,00%)
    Superior |████████████████  330  (16,50%)
             +--------------------------------------------------→ n_i
             0        200      400      600      800     1000    1200
```

### Gráfico de Setores — Grau de Instrução (n = 2.000)

```
            Fundamental
              32,50%
           ╱‾‾‾‾‾‾‾‾‾╲
          /  ░░░░░░░░░ \
         |  ░░░░░░░░░░░ |
Superior ─┤ ░░░░░░░░░░░ ├─ Médio
 16,50%  |  ▒▒▒▒▒▒▒▒▒▒ |   51,00%
          \  ▒▒▒▒▒▒▒▒▒ /
           ╲___________╱
```

| Símbolo | Categoria    | $n_i$  | $100 f_i$ |
|:-------:|:------------|-------:|----------:|
| ░░       | Fundamental |    650 |    32,50% |
| ▒▒       | Médio       |  1.020 |    51,00% |
| (branco) | Superior    |    330 |    16,50% |
| **—**   | **Total**   |**2.000**|**100,00%**|

> **Leitura:**
> - Mais da metade dos empregados (51%) possui ensino médio
> - Apenas 16,5% têm nível superior
> - O gráfico de barras facilita a **comparação entre categorias**; o de setores evidencia a **composição proporcional** do total

## Código Python utilizado

```python
import matplotlib.pyplot as plt
import numpy as np

# --- (a) Histograma de Idade ---
classes     = [20, 25, 30, 35, 40, 45, 50]
frequencias = [2, 6, 10, 8, 8, 2]

fig, ax = plt.subplots(figsize=(8, 4))
ax.bar(classes[:-1], frequencias, width=5, align='edge',
       edgecolor='white', color='steelblue')
ax.set_xlabel("Idade (anos)")
ax.set_ylabel("Frequência ($f_i$)")
ax.set_title("Histograma — Idade dos Empregados (n = 36)")
ax.set_xticks(classes)
plt.tight_layout()
plt.savefig("histograma_idade.png", dpi=150)

# --- (b) Gráfico de barras — Grau de instrução ---
categorias  = ["Fundamental", "Médio", "Superior"]
ni          = [650, 1020, 330]
cores       = ["#4e79a7", "#f28e2b", "#76b7b2"]

fig, ax = plt.subplots(figsize=(7, 4))
ax.barh(categorias, ni, color=cores, edgecolor='white')
for i, v in enumerate(ni):
    ax.text(v + 15, i, f"{v} ({v/2000*100:.1f}%)", va='center')
ax.set_xlabel("Número de empregados ($n_i$)")
ax.set_title("Grau de Instrução — Companhia MB (n = 2.000)")
ax.set_xlim(0, 1250)
plt.tight_layout()
plt.savefig("barras_grau_instrucao.png", dpi=150)
```
